# Agent 工具调用

Agent 可以根据用户问题决定是否调用工具。大模型只负责生成工具名称和参数，Python 负责执行真实函数。

为了避免 Agent 无限调用工具，可以设置 max_steps，限制一次任务中的最大模型判断轮数。

# Agent 记忆

短期记忆保存最近若干轮对话。为了控制 Token 消耗，可以使用滑动窗口，只将最近的消息发送给大模型。

长期记忆保存用户姓名、学习目标、当前项目等稳定信息。长期记忆可以存储在 JSON 或 SQLite 中。

# RAG

RAG 会先从知识库中检索与问题相关的文本，再将检索结果和用户问题一起交给大模型。

基础 RAG 通常包括文档加载、文本切块、向量化、相似度检索和答案生成。
